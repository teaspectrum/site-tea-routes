概览

荷兰东印度公司（VOC，1602—1799）是欧洲早期大规模进口茶叶的贸易公司之一。17世纪初，VOC把中国和日本茶叶运抵阿姆斯特丹，推动了欧洲饮茶风尚。荷兰人以巴达维亚（今雅加达）为亚洲总部，经好望角连接中国、日本与欧洲，运回绿茶、红茶和乌龙茶。VOC的茶路不仅是商业之路，也把中国茶具、茶礼仪与饮茶习惯带入欧洲。

历史与背景

1602年，荷兰东印度公司（Vereenigde Oost-Indische Compagnie，简称VOC）在阿姆斯特丹成立。它常被视为早期跨国股份公司之一，拥有荷兰政府在亚洲的贸易特许权，可以建立据点、签订条约、维持武装，并发行股份筹资；但它并非世界上第一家股份公司。

正山小种 巴达维亚——VOC的亚洲心脏——1619年，VOC总督扬·皮特斯佐恩·科恩（Jan Pieterszoon Coen）在爪哇岛建立了巴达维亚城（今雅加达）。巴达维亚成为VOC在亚洲的行政和贸易总部，也是茶叶采购和转运的核心枢纽。中国商船（特别是福建和广东的私商）将茶叶运至巴达维亚，VOC以白银和香料交换。巴达维亚的华人社区日益壮大，成为VOC茶叶贸易的关键中介。

长崎出岛——VOC的日本垄断——1641年，VOC将商馆从平户迁至长崎出岛。在日本锁国（Sakoku）时期（1639-1854年），VOC是唯一被允许在日本贸易的欧洲国家——但荷兰人只能待在出岛这个200米长、70米宽的人工岛上，每年仅允许一艘商船入港。VOC在此垄断了日本茶叶贸易，将日本煎茶（Sencha）和宇治抹茶（Matcha）运往欧洲。日本茶叶的独特风味让欧洲人着迷——日本茶道美学也通过VOC的商人和传教士的介绍传入欧洲。

抹茶 VOC的衰落与遗产——VOC在18世纪末衰落，1799年特许状到期，1800年公司解散。腐败、管理不善、第四次英荷战争（1780—1784年）的打击，以及英国东印度公司的竞争，共同导致了这个商业帝国的终结。但VOC的茶路遗产仍在：它推动了欧洲茶叶贸易，把中国和日本的茶文化介绍到西方。荷兰的茶钟（Thee-klok）与茶柜（Thee-kast）至今仍是荷兰物质文化的一部分。阿姆斯特丹国立博物馆（Rijksmuseum）收藏的VOC时期茶叶罐、茶具与贸易图像，记录着这段历史。

路线与范围

起点：阿姆斯特丹（VOC总部）→ 泰瑟尔岛（Texel出海口）→ 英吉利海峡 → 大西洋 → 好望角（VOC补给站）→ 毛里求斯 → 巽他海峡 → 巴达维亚（雅加达，VOC亚洲总部）→ 澳门 → 广州 → 长崎出岛（日本唯一对外窗口）→ 返程经好望角回阿姆斯特丹。VOC在巴达维亚设立亚洲总部，统管茶叶采购和转运。

旧站难度描述：中等——海上航行，季风影响，航程约6-8个月。

旧站距离：约24000公里（从阿姆斯特丹至日本长崎往返）。

旧站历时：单程约6-8个月。

旧站建议季节：利用季风，11月至次年2月南下，6月至9月北上。

地形：北海—英吉利海峡—大西洋—好望角—印度洋—巽他海峡—爪哇海—中国南海—东海

节点

01 · 阿姆斯特丹

累计里程约 0 km；海拔约 5 m；坐标 52.37, 4.9。数据语境：旧站历史线路资料，不是现代导航轨迹。

起点！VOC总部东印度公司大楼（Oost-Indisch Huis）矗立在阿姆斯特丹运河畔。每年春秋两季，VOC的“十七人董事会”（Heren XVII）在此决策茶叶采购的数量和航线。茶叶运抵后在VOC拍卖行（Oost-Indisch Huis）拍卖，来自全欧洲的商人云集竞标——这里是欧洲茶文化的发源地

02 · 泰瑟尔岛

累计里程约 80 km；海拔约 0 m；坐标 53.08, 4.82。数据语境：旧站历史线路资料，不是现代导航轨迹。

VOC船队出海口。泰瑟尔岛（Texel）是荷兰北部瓦登海中的岛屿，VOC商船在此集结编队。舰队在泰瑟尔路（Texel Roads）锚地等待顺风，有时要等数周。船员们在此与家人告别——一场远航可能意味着两年不见，许多人一去不返

03 · 好望角

累计里程约 12000 km；海拔约 0 m；坐标 -34.36, 18.47。数据语境：旧站历史线路资料，不是现代导航轨迹。

VOC在好望角设立永久补给站（1652年建立开普殖民地）。VOC花园（Company's Garden）为来往船只提供新鲜蔬果和淡水，以防止船员患上坏血病。好望角是VOC航线上最重要的中转站——船长在此汇报航行状况，修理船只，补充物资。桌山（Table Mountain）下的开普敦因VOC而兴起

04 · 巴达维亚·雅加达

累计里程约 16000 km；海拔约 0 m；坐标 -6.18, 106.83。数据语境：旧站历史线路资料，不是现代导航轨迹。

VOC亚洲总部！巴达维亚（今雅加达）是VOC在亚洲的行政和贸易中心。总督府（Stadhuis）和庞大的仓库群沿吉利翁河（Ciliwung River）而建。茶叶在此转运和仓储——中国商船将茶叶运至巴达维亚，VOC再装船运往欧洲。巴达维亚的华人社区是VOC茶叶贸易的重要合作伙伴

05 · 澳门

累计里程约 19000 km；海拔约 0 m；坐标 22.2, 113.55。数据语境：旧站历史线路资料，不是现代导航轨迹。

葡萄牙人自16世纪中叶起居留澳门；VOC多次尝试介入澳门贸易，但未能在澳门建立永久商馆。荷兰人主要转向巴达维亚，并与福建、广东沿海商人直接交易，把武夷岩茶和正山小种等运往欧洲。

06 · 广州

累计里程约 19500 km；海拔约 0 m；坐标 23.12, 113.26。数据语境：旧站历史线路资料，不是现代导航轨迹。

18世纪广州贸易体系成熟后，广州成为VOC茶叶采购的重要地点。VOC在广州设有商馆，每年茶季与行商进行大规模茶叶交易。武夷岩茶、正山小种、福建乌龙茶等经珠江运出，装船运往巴达维亚和欧洲。

07 · 长崎·出岛

累计里程约 21000 km；海拔约 0 m；坐标 32.74, 129.87。数据语境：旧站历史线路资料，不是现代导航轨迹。

日本锁国时期唯一对外开放口岸！1641-1859年间，VOC是唯一被允许在日本贸易的欧洲国家——但仅限于长崎出岛（Dejima）这个扇形的填海人工岛。VOC在此垄断日本茶叶贸易，将日本煎茶和宇治抹茶运往欧洲。出岛上的荷兰商馆长每年需到江户（东京）觐见将军，沿途收集日本各地茶叶情报

08 · 阿姆斯特丹

累计里程约 24000 km；海拔约 5 m；坐标 52.37, 4.9。数据语境：旧站历史线路资料，不是现代导航轨迹。

终点！满载茶叶的VOC商船回到阿姆斯特丹后，茶叶在VOC拍卖行拍卖，分销全欧洲。荷兰的茶叶拍卖制度影响了欧洲其他茶叶市场，伦敦、汉堡等地的拍卖会也有类似机制。VOC的茶路虽然终结于1799年特许状到期与公司解散，但它推动了欧洲饮茶风尚，将中国和日本的茶文化传播到西方世界

煎茶

煎茶是日本产量最大的绿茶，蒸青后揉捻做形；茶汤黄绿、带青草与海苔香，70–80°C冲泡最能平衡鲜味与涩味。

抹茶

抹茶是遮光栽培的碾茶经石磨或细磨制成的粉末绿茶；它的关键是遮光、蒸青、不揉与研磨，而不是“把绿茶磨成粉”。

宇治抹茶

宇治抹茶是宇治茶区与抹茶工艺结合的名称；读它要同时看产地、遮光栽培、碾茶加工与品牌，而不是把“宇治”当成一个品质形容词。

正山小种

正山小种是福建武夷山桐木关一带的小种红茶，传统上用松烟熏焙，形成松烟香和桂圆甜。它是中国最早进入欧洲市场的红茶之一，但“世界所有红茶都源自正山小种”是夸张说法，具体源流仍需史料支持。

清香型铁观音

清香型铁观音是安溪铁观音三大产品类型之一（另为浓香型、陈香型）。它以铁观音品种芽叶为原料，经萎凋、做青、杀青、揉捻、包揉、烘干制成毛茶，再经拣剔、筛分、拼配、文火烘干精制。条索紧结砂绿，汤色金黄明亮，香气清高，滋味鲜醇甘爽，音韵明显。

节点事实表

从 福州·马尾港 到 伦敦·泰晤士河，共 8 个节点；道路类型：闽江口港湾、深水良港、马六甲海峡、印度洋中继港、两大洋交汇、大西洋中继岛、北大西洋群岛、泰晤士河码头。

起点记录：起点！福州马尾港是19世纪中国最重要的茶叶出口港之一。每年5月新茶采摘后，茶箱以最快速度从武夷山经闽江运抵马尾，飞剪船在此集结竞发。码头上茶箱堆积如山，空气中弥漫着新茶的清香——船长的发令枪一响，数艘飞剪船同时升帆起航，驶向茫茫大海

终点记录：终点！飞剪船沿泰晤士河逆流而上，伦敦塔桥和圣保罗大教堂的穹顶在晨雾中浮现。1866年大茶赛中，‘太平号’于9月6日21:45 抵伦敦码头，‘阿里尔号’于22:15 抵东印度码头，相差约半小时。首船新茶抵港后，伦敦茶市随即开市竞价。

先看端点：这条路线从 福州·马尾港 出发，到 伦敦·泰晤士河 结束；全程 8 个节点，记录中出现 8 类道路（闽江口港湾、深水良港、马六甲海峡、印度洋中继港、两大洋交汇、大西洋中继岛、北大西洋群岛、泰晤士河码头）。

再看证据：节点表给出顺序、距离与道路；地图只投影 8 个有效坐标点，高程剖面只使用 8 个有高程值的节点，缺口不补零。已记录高程约 0–5 米，可据此判断翻越、河谷或平原段。

最后看边界：它是一条解释贸易与文化交流的主题路线，不是徒步、驾车或骑行轨迹；也不能用这一条路线代替整个茶贸易史。

概览

19世纪中叶，英国每年新茶上市时，最快的飞剪船（Clipper Ship）从中国福州、上海、广州等港口满载新茶，展开横跨印度洋和大西洋的竞速航行，争夺‘第一船新茶’的荣誉和巨额奖金。1866年的大茶赛（The Great Tea Race of 1866）是最著名的一次——多艘飞剪船从福州出发，经过99天航程，Taeping 与 Ariel 在9月6日深夜先后抵港，Taeping 约早半小时；由于两船分别进入不同码头，首船奖金最终由两船分配。

历史与背景

1866年5月28日，福州马尾港，多艘英国飞剪船装载新采制的武夷红茶。‘阿里尔号’（Ariel）、‘太平号’（Taeping）和‘塞里卡号’（Serica）是最大的竞争者。

飞剪船——海上的速度之王——飞剪船（Clipper Ship）是19世纪中叶最快的帆船。它们船身修长、桅杆高耸、帆面巨大，专为速度而生。在蒸汽船尚未普及的年代，飞剪船是海上最快的交通工具。一艘飞剪船可载约100万磅（约450吨）茶叶，从中国到伦敦的最快记录是99天——而普通帆船需要6-8个月。飞剪船的船长们视速度为生命，他们愿意冒着船毁人亡的风险穿越风暴带，只为比对手早几个小时抵达伦敦。

新茶溢价——速度就是金钱——为什么飞剪船要竞速？因为“第一船新茶”的价格远高于后续到达的茶叶。19世纪英国上流社会对新茶有着近乎狂热的追捧——当年新茶每磅可卖到1英镑以上，而后续到达的茶叶价格可能跌至一半。船长和船东可获得首船溢价；奖金与运费如何分配，取决于船东、租家和合同，具体数额史料不一。

99天的生死竞速——从福州出发后，三艘飞剪船各自选择了略有不同的航线。‘阿里尔号’选择了更南的航线以利用咆哮西风带的强风，‘太平号’则走了一条更直接的航线。在印度洋上，三艘船一度相距不到50海里，船员们用望远镜互相观察，调整帆面和航向。绕过好望角时，咆哮西风带的狂风巨浪撕碎了‘阿里尔号’的主帆——但船员们在风暴中爬上桅杆更换帆布，拒绝减速。进入大西洋后，‘太平号’凭借更精准的洋流判断逐渐取得领先。1866年9月5日，‘太平号’率先抵达泰晤士河口；9月6日21:45 抵伦敦码头，约半小时后，‘阿里尔号’于22:15 抵东印度码头。两艘船几乎同时到达，99天的航程最终以约半小时的差距决出先后；‘塞里卡号’约一小时后抵达——三艘船在同一天到达伦敦，这是航海史上罕见的奇迹。

正山小种 飞剪船时代的落幕——飞剪船的黄金时代只持续了约30年（1840-1870年）。1869年苏伊士运河开通后，蒸汽船可以走更短的航线，飞剪船的速度优势丧失。1870年代后，蒸汽船逐渐取代了飞剪船，茶船竞速的浪漫时代宣告结束。但1866年的大茶赛永远留在了航海史和茶文化史上——它代表了人类对速度的极致追求，也见证了茶叶贸易如何驱动了航海技术的进步。如今，福州马尾港和伦敦泰晤士河畔的茶仓遗址，默默诉说着那段飞剪船竞速的黄金岁月。

路线与范围

起点：福州马尾港（新茶装船）→ 厦门港 → 香港 → 南海 → 新加坡海峡 → 印度洋 → 毛里求斯（补给站）→ 好望角 → 圣赫勒拿岛 → 亚速尔群岛 → 英吉利海峡 → 伦敦泰晤士河码头（终点）。三艘飞剪船几乎同时出发，各自选择略微不同的航线以争取优势——穿越咆哮西风带时全帆疾驰，帆布撕裂仍不减速。

旧站难度描述：极高——纯靠风帆动力，绕过好望角，穿越咆哮西风带，航程漫长且充满危险。

旧站距离：约22000公里（从福州至伦敦）。

旧站历时：飞剪船最快99天，普通帆船约6-8个月。

旧站建议季节：5-6月新茶上市时出发。

地形：海上航线——中国南海、印度洋、好望角、大西洋、英吉利海峡

02 · 香港·维多利亚港

累计里程约 300 km；海拔约 0 m；坐标 22.3, 114.17。数据语境：旧站历史线路资料，不是现代导航轨迹。

远东最繁忙的茶叶转运港。飞剪船经厦门后抵达香港，在此补充淡水、新鲜食物和船具。香港开埠后迅速成为茶叶贸易中心，怡和洋行、宝顺洋行等在此设有大型茶仓。船长们在港口的俱乐部里交换风速与洋流情报，为接下来的长途竞速制定策略

03 · 新加坡海峡

累计里程约 3200 km；海拔约 0 m；坐标 1.28, 103.84。数据语境：旧站历史线路资料，不是现代导航轨迹。

马六甲海峡咽喉，连接南海与印度洋的战略水道。飞剪船穿过新加坡海峡时需精准利用季风——西南季风期顺风顺水，东北季风期则需曲折航行。海峡两岸的热带雨林和香料岛屿是飞剪船在印度洋航段前的最后绿色风景

04 · 毛里求斯·路易港

累计里程约 8000 km；海拔约 0 m；坐标 -20.16, 57.5。数据语境：旧站历史线路资料，不是现代导航轨迹。

印度洋中途重要补给站。飞剪船穿越赤道无风带后在毛里求斯停靠，补充淡水、新鲜蔬果和朗姆酒。路易港是英国皇家海军在印度洋的基地，港口设施完善。船长在此检查船体，修理被风浪撕裂的帆布——接下来将面对最危险的咆哮西风带

05 · 好望角

累计里程约 12000 km；海拔约 0 m；坐标 -34.36, 18.47。数据语境：旧站历史线路资料，不是现代导航轨迹。

全程最危险航段！印度洋与大西洋在此交汇，咆哮西风带（Roaring Forties）常年狂风巨浪。飞剪船在此不减速，反而升起全部帆布利用西风疾驰——“好望角”在航海者口中是“风暴角”。1866年大茶赛中，三艘飞剪船在此段展开了最激烈的追逐，帆布多次撕裂仍不停歇

06 · 圣赫勒拿岛

累计里程约 15000 km；海拔约 0 m；坐标 -15.97, -5.71。数据语境：旧站历史线路资料，不是现代导航轨迹。

大西洋中继站，拿破仑被流放并长眠之地。飞剪船在绕过好望角后经南大西洋抵达圣赫勒拿，短暂停靠补充淡水。船员们在此眺望拿破仑的故居——龙坞德庄园（Longwood House），感叹这位曾征服欧洲的皇帝最终困于此孤岛，而茶叶的远征仍在继续

07 · 亚速尔群岛

累计里程约 19500 km；海拔约 0 m；坐标 38.52, -28.32。数据语境：旧站历史线路资料，不是现代导航轨迹。

进入欧洲水域的最后补给点。亚速尔群岛位于北大西洋中央，是葡萄牙的海外领土。飞剪船在此补充最后一批淡水后，向英吉利海峡发起最后冲刺。船员们的心跳加速——伦敦近在眼前，而竞争对手可能就在身后数海里处紧追不舍

终点！飞剪船沿泰晤士河逆流而上，伦敦塔桥和圣保罗大教堂的穹顶在晨雾中浮现。1866年大茶赛中，‘太平号’约早半小时抵港，‘阿里尔号’紧随其后——两船几乎同时出现在泰晤士河口，整个伦敦为之沸腾。第一船新茶抵达后，伦敦茶市立即开市竞价，新茶价格一日数变

正山小种

正山小种是福建武夷山桐木关一带的小种红茶，传统上用松烟熏焙，形成松烟香和桂圆甜。它是中国最早进入欧洲市场的红茶之一，但“世界所有红茶都源自正山小种”是夸张说法，具体源流仍需史料支持。

祁门红茶

祁门红茶是安徽祁门一带的工夫红茶，以“祁门香”著称，香气常被描述为花香、果香和蜜糖香的复合。按 GB/T 13738.2-2017，它属于工夫红茶；具体产地、等级和地理标志使用资格应看包装与标准。

福州茉莉花茶

福州是中国茉莉花茶的发源地和核心产区。以烘青绿茶为茶坯,与福州伏天茉莉花多次窨制而成。成品茶花交融,花香浓郁鲜灵持久,茶味醇和甘甜。2014年福州茉莉花茶窨制技艺被列入国家级非物质文化遗产。

福鼎白牡丹

福鼎白牡丹是以一芽一、二叶制成的白茶，芽叶连枝、绿叶夹银白毫心，汤色杏黄，毫香与花香并见。按 GB/T 22291-2017，白牡丹的原料嫩度介于白毫银针与贡眉、寿眉之间；福鼎是主要产区之一。

福鼎白琳工夫

白琳工夫是"闽红三大工夫"之一(与坦洋工夫、政和工夫齐名),产于福鼎白琳镇——福鼎白茶的故乡。以福鼎大白茶品种制作工夫红茶,香气兼具白茶的清雅和红茶的蜜甜——"白茶基因中的红茶风味",这在红茶世界中独一无二。外形紧细秀丽匀整,色泽乌润金毫显露。冲泡后蜜甜花香交织缠绵——蜜甜的底韵中透出白茶品种特有的清雅毫香。

清香型铁观音

清香型铁观音是安溪铁观音三大产品类型之一（另为浓香型、陈香型）。它以铁观音品种芽叶为原料，经萎凋、做青、杀青、揉捻、包揉、烘干制成毛茶，再经拣剔、筛分、拼配、文火烘干精制。条索紧结砂绿，汤色金黄明亮，香气清高，滋味鲜醇甘爽，音韵明显。
